A tiny Python program (standard library only) that writes one deadpan excuse an AI agent gives for missing a deadline: its context window filled up, so it compressed the task, the deadline, and its own job description into a single token. The output is a single line of 147 characters, inside the competition's 1–200 character gate.

## Run it

```sh
python3 main.py
```
